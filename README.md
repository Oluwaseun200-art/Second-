## Features
- Origin and destination selection
- Input validation
- Dijkstra shortest-path routing
- Route sequence display
- Distance and estimated travel time
- Responsive mobile/desktop interface
- GitHub Pages compatible static deployment

## Important prototype note
The route network in `script.js` uses illustrative distances and times. It should be replaced or validated with authoritative University of Ibadan transportation data before operational use.

## Run locally
Open `index.html` in a modern browser. No server is required.

## GitHub Pages deployment
1. Create a new GitHub repository, for example `campus-transportation-routing-system`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch** and choose the `main` branch and `/root` folder.
5. Save and wait for GitHub Pages to publish.
6. The resulting link will normally follow this pattern:
   `https://YOUR-GITHUB-USERNAME.github.io/campus-transportation-routing-system/`

A real GitHub URL cannot be supplied until a GitHub account/repository is created and published.
